# Recipes for pgsafe-mcp

This folder contains verified production recipes and client configurations for integrating `pgsafe-mcp` with autonomous AI agents (Claude Desktop, Cursor, Windsurf, Antigravity).

## Contents
1. `claude_desktop_config.json`: Ready-to-use configuration for Claude Desktop.
2. `advanced_agent_workflow.py`: End-to-end Python script demonstrating advanced tool calling and resilience patterns.
3. `docker-compose.genesis-stack.yml`: Multi-container Docker deployment recipe in the repository root.
